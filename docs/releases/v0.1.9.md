# emachine v0.1.9

Interface refresh now works over slower connections. Earlier AppImages stopped downloading a file after 15 seconds, even while data was arriving.

Choose **Refresh** and then **Refresh interface**. The client lets a download continue while it receives data. If the connection drops or the server temporarily fails, it retries the affected file up to twice. Your current interface stays open until all files pass verification.

Replace your AppImage with this release and relaunch emachine to get the new downloader. You can keep your existing interface source, connections, and preferences.
