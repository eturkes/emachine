# emachine v0.1.2

The desktop interface can now refresh without replacing the AppImage.

Open **Refresh** and choose one trusted emachine server. Confirm the source in the native trust prompt.
The app checks for interface changes each minute. Select **Refresh interface** to apply a new revision.
Only changed web files are transferred. The application process and AppImage stay unchanged.

The loader checks file sizes, hashes, and the desktop bridge version before opening a complete revision.
It retains a verified local interface for offline startup. Failed initialization restores the previous interface.
Use **Control+Shift+B** for native bundled recovery when the interface controls are unavailable.

A refresh preserves saved connections and project selection. Server terminals and jobs keep running.
Save work in open views before refreshing; temporary view state can be lost.

**Updates** still handles Electron, native integration, and desktop security updates through AppImage releases.
Clients before `0.1.2` need this runtime update once. Later UI-only changes need a web deployment, not another AppImage release.

See [interface updates and recovery](../interface-updates.md) for source trust, deployment, and compatibility requirements.
