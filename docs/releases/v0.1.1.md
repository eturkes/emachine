# emachine v0.1.1

The Linux desktop client now has manual update controls.

Select **Updates**, then **Check for updates**. Select **Download update** when a newer stable release is available.
After the download, select **Restart and install**. Nothing downloads or installs automatically.

Updates preserve your client connection settings. They do not update machine servers or project views.
The local installer uses a stable AppImage filename, so its launcher continues to work after an update.

Release assets include `latest-linux.yml`. Release preparation validates its version, filename, size, and checksum against the exact AppImage.

Version `0.1.0` has no updater. Install this AppImage once to receive later releases through the update controls.
Keep the AppImage in a writable folder. Rename it to `emachine.AppImage` before creating a shortcut.
