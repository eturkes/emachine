# emachine v0.1.8

This AppImage bundles project prompt history and the latest terminal interface.

## Project prompt history

Open a project's terminal and choose **History**, beside **Prompts**. Scroll through that project's recorded Claude Code prompts, newest first, with local timestamps and selectable text. **Load older** continues through earlier entries; **Reload history** fetches newly recorded prompts; **Copy prompt** copies the displayed text exactly.

History includes the project and its subdirectories. Available pasted text is restored, and entries indicate when some pasted content could not be recovered. Browsing does not send input to the terminal. This feature requires a machine server with the prompt-history endpoint; the CachyOS server has already been updated.

## Update the desktop client

Replace the previous AppImage with this release and relaunch it. Saved connections and preferences stay in the existing desktop profile.

If a previously downloaded interface still opens, press **Ctrl+Shift+B** and confirm the native prompt to use this AppImage's bundled interface. You can also press **Alt** to show the native **Interface** menu. Open a project terminal and choose **History**.

For later interface-only updates, open **Refresh**, enter your server's HTTPS base address as **Interface source**, then choose **Use this source** and confirm **Trust source**. The app checks the trusted source for new revisions. AppImage replacement remains a separate GitHub download.

## Other bundled interface changes

- Select and preview reusable prompt sections, with steering where required.
- Open machine-wide **General** terminal tabs.
- Keep terminal controls accessible in compact layouts and recover connections after stalled requests.
- Use the native light terminal background while preserving application-supplied colors.

The release contains no configured machine identities, addresses, or credentials. The AppImage does not install or replace machine servers. Server terminals and jobs remain independent of the desktop client.
