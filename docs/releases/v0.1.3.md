# emachine v0.1.3

The desktop header now uses text labels instead of platform-specific or symbolic controls.
Use **Workspaces**, **Theme**, **Settings**, and **Refresh** from the header. The terminal tab is now plain **Terminal** text, and the connection-route badge is no longer shown there.

The built-in AppImage updater has been removed. Install desktop runtime updates from GitHub Releases with your external update method.
Interface-only updates still use **Refresh** and do not replace the AppImage.

Terminal rendering now uses standard-width JetBrains Mono for clearer shell output.
Emachine also attaches to the exact project-named zmx session, so browser and SSH attachments can share the same persistent terminal session.

Release assets remain the Linux x86-64 AppImage, checksums, release metadata, and `latest-linux.yml` for external tooling.
