# emachine v0.1.0

The first release of the personal, multi-machine project command center.

## Included

- A Linux x86-64 AppImage with the bundled web interface, machine connections, project sidebar, and per-project tabs.
- Persistent zmx terminals through the MoonBit machine server, with reconnection and explicit control transfer between devices.
- Independent project features, validated activation, diagnostics, server-owned jobs, and external recovery checkpoints.
- An installable PWA, phone-sized terminal controls, light and dark themes, and cached application-shell support.

## Linux download

Download `emachine-0.1.0-x86_64.AppImage`, `SHA256SUMS`, and `release.json` from the assets below.

```sh
sha256sum -c SHA256SUMS
chmod +x emachine-0.1.0-x86_64.AppImage
./emachine-0.1.0-x86_64.AppImage
```

Without a FUSE mount helper:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./emachine-0.1.0-x86_64.AppImage
```

Add your machine's HTTPS address in **Machines**. The release contains no saved machine connections or credentials.
The AppImage is a client. Build and install the MoonBit server separately on each Linux project machine.

## Boundaries

Direct Tailscale access is available. Public browser access needs a separately configured authenticated gateway; the optional FreeBSD deployment is pending.
Native bcachefs recovery and physical iPhone/Android behavior remain unverified. Copy-based recovery and phone-sized Chromium have automated coverage.
This experimental release targets Linux x86-64 only and does not include an automatic updater.
