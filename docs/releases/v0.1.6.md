# emachine v0.1.6

The terminal's **Copy** and **Paste** buttons now have clipboard access in the desktop client.
Copy writes the selected terminal text. An empty selection leaves the clipboard unchanged.
Paste reads the clipboard and sends text only while the terminal has control of its connection.

Clipboard permission applies only to the main `emachine://app` window and its main frame.
Embedded project views, other windows, and external pages do not receive this permission.
Camera and microphone access still require explicit approval.

Replace the AppImage and relaunch the client to apply this fix. The interface **Refresh** control cannot change native permissions.
Saved connections remain in the desktop profile. Server terminals and jobs remain independent of the client.

The release also includes the current interface with project phases and Claude session activity in the sidebar.
Release checks exercise actual system clipboard copying and pasting in the packaged client, without test-granted permissions.
They also check that embedded pages cannot read or overwrite the clipboard.

Release assets contain no configured machine identities, addresses, or credentials.
