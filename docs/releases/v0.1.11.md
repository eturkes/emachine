# emachine v0.1.11

The Linux AppImage can remember a direct Tailscale networking preference. Use it if the desktop client reaches a private machine only with a proxy bypass and an IPv4 hostname override.

Open the AppImage and press **Alt**. Choose **Network → Direct Tailscale networking**, then **Save setting**. Quit and reopen the AppImage from your usual launcher.

On each launch with this setting enabled, emachine asks the local Tailscale client for current peer IPv4 addresses. It keeps the configured hostnames for HTTPS and WebSocket certificate verification. When direct Tailscale networking is active, all AppImage connections bypass proxies. The setting applies only to this desktop profile. Remove custom routing flags from the launcher so the AppImage can manage routing.

The **Network** menu shows which mode is active for this launch. If you need your normal proxy settings, clear the checkbox and restart.
