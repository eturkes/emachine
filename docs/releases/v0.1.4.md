# emachine v0.1.4

The AppImage now includes the same grayscale logo and neutral light and dark themes as the iOS web app.
The launcher icon, window icon, controls, and terminal defaults no longer use decorative green accents.
Warnings and errors retain their functional colors.

Replace the AppImage and relaunch the desktop client to update its native icons.
The **Refresh** control updates the interface, but it does not replace the AppImage or its launcher icon.
Connection settings remain in the existing desktop profile. Machine servers and project views are unchanged by the client update.

The desktop bundle also includes the expanded project rail, terminal shortcuts, and touch-scrolling changes available in the web interface.
The release test checks packaged icons against the PWA assets and checks both themes in the running AppImage.

Release assets remain the Linux x86-64 AppImage, checksums, release metadata, and `latest-linux.yml` for external tooling.
