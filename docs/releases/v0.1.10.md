# emachine v0.1.10

This AppImage includes the interface that waits up to 30 seconds for the last available machine address. Cached workspaces show **Connecting** while the first inventory request is pending.

Close the previous AppImage and launch this one. If an older saved interface opens, press **Ctrl+Shift+B** and confirm **Reload** to use the bundled interface. This works offline and keeps your machine connections and preferences.

If a later refresh fails, the dialog identifies the file it tried to download. It shows the HTTP status, timeout, or recognized network error, such as a DNS lookup failure, refused connection, or rejected certificate. An invalid manifest or a cache permission problem has its own message.
