# emachine v0.1.7

The desktop client now remembers its window size and whether it was maximized.
Resize or maximize the window, then close it. The next launch restores that state.
Restoring a maximized window returns it to the previous normal size.
Closing while minimized keeps the last normal or maximized state for the next launch.

Saved dimensions fit within the current display's work area. Missing or damaged window preferences use the default size.
At fractional display scaling, Electron can round the restored dimensions by a few pixels. The saved size does not grow across repeated launches.
The client saves window preferences in its existing desktop profile. Saved connections remain in that profile.

Replace the AppImage and relaunch the client to apply this change. The interface **Refresh** control cannot update native window behavior.
Server terminals and jobs remain independent of the client.

Release checks exercise resizing, maximizing, restoring, minimized and fullscreen closure, and repeated launches at fractional scaling with temporary profiles in the exact packaged AppImage.
Release assets contain no configured machine identities, addresses, or credentials.
